# Play Store Compliance — Zero-Key Migration Plan

> **For Hermes:** Implement this plan task-by-task in order. Build and verify at the end.
> **Goal:** Replace the current NewPipe+ExoPlayer+InnerTube stack with the official YouTube IFrame Player API (android-youtube-player) + a curated asset-based video list, making the app eligible for Google Play Store distribution **with zero API keys**.
> **Architecture:** Two independent replacements: (A) playback moves from NewPipe+ExoPlayer to `YouTubePlayerView` (IFrame WebView), (B) video discovery moves from InnerTube API to a `music_videos.txt` asset file that a GitHub Actions workflow refreshes weekly by scraping public YouTube RSS feeds.
> **Tech Stack:** Kotlin, Android Views, Pierfrancesco Soffritti's `android-youtube-player:core:12.1.0`, GitHub Actions (Python/yt-dlp), Gradle 9.3

---

## Why This Change Is Needed

Google Play Store **bans** apps that play YouTube content without the official player:

| Current (banned) | Replacement (compliant) |
|---|---|
| **NewPipe Extractor** reverse-engineers stream URLs | **YouTubePlayerView** renders the official IFrame Player API |
| **ExoPlayer** plays extracted streams natively, bypassing ads | Official player serves ads, respects background playback |
| **InnerTube API** (undocumented, spoofed headers) for search | **`assets/music_videos.txt`** — curated list of 1000+ video IDs |
| **`YouTubeSearchService.kt`** parses InnerTube JSON | **GitHub Actions** scrapes public YouTube RSS feeds weekly |
| API key needed for Data API v3 | **No API key anywhere** — RSS feeds are public, no auth required |

## Task 2: Create VideoProvider.kt

**Objective:** Read the video list from assets and provide random selections by year.

**File:** Create `app/src/main/java/com/turbolego/songguesser/VideoProvider.kt`

```kotlin
package com.turbolego.songguesser

import android.content.Context
import java.io.BufferedReader
import java.io.InputStreamReader

/**
 * Provides random YouTube video IDs from the curated asset file.
 * Zero network calls, zero API keys — entirely offline.
 */
object VideoProvider {

    data class VideoEntry(
        val id: String,
        val year: Int,
        val title: String = ""
    )

    private var cachedVideos: List<VideoEntry> = emptyList()
    private var yearIndex: Map<Int, List<VideoEntry>> = emptyMap()
    private var allYears: List<Int> = emptyList()

    /**
     * Load videos from the asset file. Call once on app startup.
     */
    fun load(context: Context) {
        if (cachedVideos.isNotEmpty()) return
        val videos = mutableListOf<VideoEntry>()
        try {
            context.assets.open("music_videos.txt").use { inputStream ->
                BufferedReader(InputStreamReader(inputStream)).useLines { lines ->
                    for (line in lines) {
                        val trimmed = line.trim()
                        if (trimmed.isEmpty() || trimmed.startsWith("#")) continue
                        val parts = trimmed.split(",", limit = 3)
                        if (parts.size >= 2) {
                            val id = parts[0].trim()
                            val year = parts[1].trim().toIntOrNull()
                            val title = if (parts.size >= 3) parts[2].trim() else ""
                            if (id.isNotEmpty() && year != null) {
                                videos.add(VideoEntry(id, year, title))
                            }
                        }
                    }
                }
            }
        } catch (e: Exception) {
            android.util.Log.e("VideoProvider", "Failed to load videos", e)
        }
        cachedVideos = videos
        yearIndex = videos.groupBy { it.year }
        allYears = yearIndex.keys.sorted()
    }

    /**
     * Get a random video ID. Optionally from a specific year.
     */
    fun getRandomVideoId(year: Int? = null): String? {
        val pool = if (year != null) {
            yearIndex[year]
        } else {
            cachedVideos.ifEmpty { null }
        }
        return pool?.randomOrNull()?.id
    }

    /**
     * Get a random video ID from a random year (weighted by modern years).
     */
    fun getRandomVideoIdWeighted(): String? {
        val year = YearRandomizer.prioritizeModernYears(
            availableYears = allYears
        )
        return getRandomVideoId(year)
    }

    /**
     * Get all available years.
     */
    fun getAvailableYears(): List<Int> = allYears

    /**
     * Get the total number of cached video entries.
     */
    fun size(): Int = cachedVideos.size
}
```

## Task 6: Adapt YearRandomizer

**Objective:** Make `YearRandomizer.prioritizeModernYears()` work with available years from the asset file (not just a min/max range).

**File:** Modify `app/src/main/java/com/turbolego/songguesser/YearRandomizer.kt`

Add an overload:
```kotlin
/**
 * Pick a random year weighted toward modern years,
 * but only from [availableYears] (years present in the asset file).
 */
fun prioritizeModernYears(availableYears: List<Int>): Int {
    if (availableYears.isEmpty()) return 2000
    if (availableYears.size == 1) return availableYears.first()

    // Weighted toward newer years in the list
    val weighted = mutableListOf<Int>()
    for ((index, year) in availableYears.withIndex()) {
        val weight = if (index > availableYears.size / 2) 3 else 1
        repeat(weight) { weighted.add(year) }
    }
    return weighted.random()
}
```

Keep the original method as fallback.

```python
#!/usr/bin/env python3
"""
Refresh the music_videos.txt asset file by scraping YouTube's public RSS feeds.
Uses yt-dlp to search for popular music videos by year.
No API keys needed — YouTube RSS feeds are public, no auth required.
"""

import subprocess
import os
import sys
from collections import OrderedDict

ASSET_PATH = "app/src/main/assets/music_videos.txt"
YEARS = list(range(1980, 2026))
VIDEOS_PER_YEAR = 15

def fetch_videos_by_year(year: int) -> list[tuple[str, str]]:
    """Fetch popular music videos for a given year using yt-dlp."""
    query = f"popular songs {year} music"
    cmd = [
        "yt-dlp",
        f"ytsearch{VIDEOS_PER_YEAR}:{query}",
        "--print", "%(id)s,%(title)s",
        "--no-warnings",
        "--ignore-errors",
        "--flat-playlist",
    ]
    try:
        result = subprocess.run(cmd, capture_output=True, text=True, timeout=60)
        videos = []
        for line in result.stdout.strip().split("\n"):
            line = line.strip()
            if not line or "," not in line:
                continue
            parts = line.split(",", 1)
            if len(parts) == 2 and parts[0]:
                videos.append((parts[0].strip(), parts[1].strip()))
                print(f"  {year}: {parts[0]} — {parts[1][:50]}")
        return videos
    except subprocess.TimeoutExpired:
        print(f"  Timeout fetching year {year}")
        return []
    except Exception as e:
        print(f"  Error fetching year {year}: {e}")
        return []

def main():
    # Read existing entries to preserve manual additions
    existing = OrderedDict()
    header_lines = []
    if os.path.exists(ASSET_PATH):
        with open(ASSET_PATH) as f:
            for line in f:
                stripped = line.strip()
                if stripped.startswith("#"):
                    header_lines.append(line)
                elif stripped and "," in stripped:
                    vid = stripped.split(",")[0].strip()
                    existing[vid] = stripped

    print(f"Existing entries: {len(existing)}")
    print("Fetching fresh videos by year...")

    new_count = 0
    for year in YEARS:
        videos = fetch_videos_by_year(year)
        for vid_id, title in videos:
            if vid_id not in existing:
                # Clean title: strip quotes, limit commas
                clean_title = title.replace('"', '').replace("'", "")
                existing[vid_id] = f"{vid_id},{year},{clean_title}"
                new_count += 1

    # Write updated file
    with open(ASSET_PATH, "w") as f:
        f.writelines(header_lines)
        f.write(f"# Auto-updated: {len(existing)} entries ({new_count} new)\n")
        f.write("# Format: videoId,year,title\n")
        f.write("# Generated by scripts/refresh_videos.py\n\n")
        for entry in existing.values():
            f.write(entry + "\n")

    print(f"\nDone: {len(existing)} total entries ({new_count} new)")

if __name__ == "__main__":
    main()
```

## Risks and Tradeoffs

| Concern | Assessment | Mitigation |
|---|---|---|
| **Video list goes stale** | New hits aren't added until weekly refresh | Weekly GH Action is fast enough |
| **Some videos get deleted** | IDs in the file may become unavailable | `YouTubePlayerView` shows error state; always have 1000+ entries |
| **Region-locked videos** | Some content blocked in certain countries | File spans diverse years/artists; user can skip |
| **No dynamic year query** | Can't search "songs from 1995" live | The asset file covers all years 1980-2025; pick random from target year |
| **Asset file size** | 1000+ entries ~50 KB | Tiny — loads instantly |
| **GH Action uses yt-dlp** | Need yt-dlp maintained | yt-dlp is actively maintained; script handles failures gracefully |
